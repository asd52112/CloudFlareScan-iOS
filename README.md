# CloudFlareScan iOS

CloudFlareScan 的 SwiftUI/TrollStore 版本。支持 IPv4 扫描、TCP 延迟、Cloudflare 机房识别、下载测速和 CSV 导出。

## Windows 构建 IPA

1. 将此目录上传到 GitHub 仓库。
2. 打开 Actions，运行 `Build IPA`。
3. 在构建结果的 Artifacts 中下载 `CloudFlareScan-unsigned.ipa`。
4. 将 IPA 传到 iPhone，用 TrollStore 安装。

本项目仅用于本人拥有或获授权网络的合法测速。
